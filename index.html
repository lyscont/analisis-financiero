6. Laboratorio de interpretación financiera

Observa la evidencia, explica posibles causas y formula recomendaciones. Los comentarios cambian con tus cifras.

Tu interpretación como analista — evaluador formativo V3

Elige un tema, redacta primero y recibe comentarios automáticos. La valoración es orientativa y no reemplaza la revisión del docente.

Uso educativo. Estas observaciones son interpretaciones descriptivas y alertas, no diagnósticos ni auditoría. Se requiere revisar notas, sector, políticas contables y flujo de efectivo para concluir sobre causas y riesgos. El análisis usa dos años y datos ficticios o aportados por el usuario.

Para usar en GitHub Pages

Renombra este archivo como index.html, súbelo a un repositorio público y activa Settings → Pages → Deploy from a branch → main → /(root). Abre la URL publicada y enlázala desde UTP+Class. No se requiere servidor propio.
