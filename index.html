1. Preparar los datos

Comienza con el caso de ejemplo, modifica las cifras o carga tu Excel/CSV.

Formato esperado: columnas Estado | Código | Rubro | Año 1 | Año 2. Para XLSX se utiliza la biblioteca SheetJS; la carga CSV funciona sin bibliotecas externas. Los datos quedan en tu navegador.

2. Estado de Situación Financiera

Cifras en soles (S/). Edite las celdas blancas.
Rubro2024AV año 12025AV año 2Variación S/AH %

AV = rubro / total activo (ESF) o ventas netas (ER). AH = (año 2 − año 1) / |año 1| × 100. Si el valor base es cero, se muestra «N/D».

6. Interpretación y reporte

Uso educativo: los resultados se calculan a partir de datos ingresados por el estudiante. La interpretación automática aplica reglas didácticas, no reemplaza el criterio profesional ni la revisión de estados financieros completos.

Para usar en GitHub Pages

Renombra este archivo como index.html, súbelo a un repositorio público y activa Settings → Pages → Deploy from a branch → main → /(root). Abre la URL publicada y enlázala desde UTP+Class. No se requiere servidor propio.
